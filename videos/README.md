# Hackervideo

Legt hier euer Einstiegsvideo als `intro.mp4` ab (H.264 und AAC, damit es auch in Safari läuft).

Der Knopf «Hackervideo» auf `spielleitung.html` spielt `videos/intro.mp4` im Vollbild ab. Fehlt die Datei, zeigt die Spielleitungsansicht als Ersatz eine getippte Hackernachricht von NULLBYTE mit Alarmton.

Tipp: Eine Datei unter 100 MB lässt sich direkt ins GitHub-Repository hochladen. Grössere Videos besser lokal vom Laptop abspielen.
