PROTOKOLL 3: NETZWERKE

Netzwerkplan des Schulnetzes
ROUTING GESTÖRT

Auftrag: Die Daten müssen von Server A zu Server Z fliessen. Findet den kürzesten Weg (am wenigsten Verbindungen), der über keinen infizierten (roten) Server führt. Addiert die Kennzahlen aller Server auf dem Weg, auch von A und Z. Die Summe ist der Override-Code (dreistellig eingeben).

Unser Weg: ________________________________
Summe der Kennzahlen: ________

Legende: blaue Server = Start und Ziel, weisse Server = sauber, rote Server = von NULLBYTE infiziert. Die Zahl rechts unten ist die Kennzahl des Servers.
