Den sauberen Weg finden

NULLBYTE hat Server im Schulnetz infiziert. Die Daten müssen von Server A zu Server Z fliessen, ohne einen infizierten Server zu berühren. Mit dem richtigen Weg erhaltet ihr den Override-Code und rettet das System.

So geht ihr vor

  1. Streicht alle Verbindungen zu den roten (infizierten) Servern durch.
  2. Sucht den kürzesten sauberen Weg von A nach Z, also den mit den wenigsten Verbindungen.
  3. Addiert die Kennzahlen aller Server auf dem Weg, auch von A und Z. Die Summe ist der dreistellige Override-Code.

Netzwerkplan

Blau = Start und Ziel, weiss = sauber, rot = von NULLBYTE infiziert. Die Zahl rechts unten ist die Kennzahl des Servers, jede Linie ist eine Verbindung.
