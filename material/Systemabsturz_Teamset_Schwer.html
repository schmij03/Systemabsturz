SICHERHEITSPROTOKOLL 2 · ALGORITHMEN

Virenscanner programmieren

STUFE SCHWER

NULLBYTE hat einen Virus ins Netzwerk geschleust. Programmiert im Notfall-Terminal den Antiviren-Roboter ANTI-V so, dass er das Ziel erreicht und unterwegs die drei Viren-Signaturen einsammelt. Rote Felder sind infiziert: Betritt ANTI-V eines, ist er verloren.

So geht ihr vor

  1. Zieht die Blöcke aus der Werkzeugleiste unter «wenn Programm startet».
  2. Startet das Programm oder lasst es Schritt für Schritt laufen und beobachtet, welcher Block gerade arbeitet.
  3. Sammelt ANTI-V auf dem Weg ins Ziel die richtigen Signaturen ein, ist Protokoll 2 geknackt.

Eure Blöcke

Steuerung«wiederhole bis Ziel erreicht», «falls ‹ › dann», «falls ‹ › dann sonst»
Bewegung«gehe 1 Feld vor», «drehe dich nach rechts», «drehe dich nach links»
Fühlen«rechts frei?», «vorne frei?», «links frei?», «rechts infiziert?», «vorne infiziert?»
Operatoren«‹ › und ‹ ›», «‹ › oder ‹ ›», «nicht ‹ ›»
frei heisst: Auf dem Nachbarfeld steht keine Mauer. infiziert heisst: Das Feld ist rot.
Rechts und links gelten aus der Sicht von ANTI-V. Stellt euch hinter den Roboter!

Regeln des Terminals

  • Schleife ist Pflicht: Ohne «wiederhole bis Ziel erreicht» startet das Programm nicht.
  • Blocklimit: Höchstens 15 Blöcke. Ist das Limit erreicht, werden die Blöcke grau.
  • Energie: ANTI-V kann höchstens 16 Felder gehen. Umwege enden mit «Energie leer!».
  • Effizienzbonus: 10 Punkte plus 5 Punkte für jeden Block unter dem Limit. Nach dem Lösen dürft ihr weiter optimieren.

SICHERHEITSPROTOKOLL 3 · NETZWERKE

Routing reparieren

STUFE SCHWER

Virus gefunden! Doch NULLBYTE hat Server im Schulnetz infiziert. Die Daten müssen von Server A zu Server Z fliessen, damit ihr den Override auslösen könnt.

Euer Auftrag

  1. Sucht auf dem Netzwerkplan den Weg von Server A zu Server Z mit möglichst wenigen Verbindungen.
  2. Der Weg darf keinen infizierten (roten) Server berühren.
  3. Zählt die Kennzahlen aller Server auf eurem Weg zusammen, Server A und Server Z eingeschlossen.
  4. Die Summe ist der Override-Code. Gebt ihn dreistellig im Terminal ein (zum Beispiel 065) und drückt den roten Buzzer!
